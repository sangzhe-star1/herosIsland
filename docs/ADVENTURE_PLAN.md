# 横版冒险闯关改造方案（待确认，暂不实施）

> 目标：把「顶气球」这类"站着点一点"的小游戏，升级成**儿童版冒险岛 + 奥特曼闯关**——
> 角色可控、场景可探索、有机关有小怪有 Boss、每关 2–4 分钟有起承转合。
>
> 本文档只是**计划**。确认后再分阶段开发，每阶段自测 + 截图 + 报告。

---

## 0. 先说结论：不是从零开始，也不是改改图

盘点下来，规格书里要的东西**已经有一半躺在代码库里**，只是散在 12 个互不相通的模板中：

| 规格书要求 | 现状 | 结论 |
|---|---|---|
| 角色移动/跳跃/土狼时间/二段跳/绳索/弹簧/移动平台 | `platformer.gd`（1272 行）**全都有** | 直接搬 |
| 待机/奔跑/跳跃/落地/受击/欢呼动作 | `SkinnedCharacter` 17 个动作动词 | 直接用 |
| 技能按钮 + 环形冷却 + 大招蓄能 + 血条 + 攻击预警 | `monster_duel.gd`（864 行）**全都有** | 抽出来复用 |
| 怪兽血条 / 多怪 / 弱点 | `monster_expedition.gd` | 抽出来复用 |
| 关卡数据 JSON 化 | 54 关早就是 JSON | 扩展格式 |
| 星星/金币/徽章/贴纸/服装/道具/角色解锁存档 | `SaveManager`（511 行）全有 | 加 3 个字段 |
| 图形化提示、禁止图标、粒子、按下反馈 | `UiKit` / `Juice` / `IconLibrary` | 直接用 |
| 难度档位 | 家长中心已有 轻松/普通/挑战 | 直接接 |

**真正缺的是三样东西**，也就是这次要做的：

1. **战斗**——跳跃关里没有攻击、没有小怪、没有 Boss
2. **可交互物件**——没有箱子、开关、钥匙门、落石、火焰、NPC、检查点
3. **关卡节奏**——现在一关就是"从左跑到右"，没有"探索→任务→机关→小游戏→Boss→宝箱"的段落结构

所以方案不是"再写一个模板"，而是**把已有的两根柱子（跳跃物理 + 决斗战斗）焊在一起，中间插一条 JSON 驱动的段落时间线**。

## 1. 架构：一个模板，一条时间线

新模板 `platform_adventure`。一关 = **一条横向长条地图** + **一串按 x 坐标排列的"段落"（beat）**。

```
关卡 JSON
  └─ sections: [ {kind, at, ...}, {kind, at, ...}, ... ]
        │
        ├─ kind: "collect"   收集 N 个能量球
        ├─ kind: "hazard"    落石/火焰区/追逐段
        ├─ kind: "enemy"     一小群会主动攻击的小怪
        ├─ kind: "switch"    机关/钥匙门/推箱子/升降台
        ├─ kind: "puzzle"    儿童知识小游戏（就地弹出，不切场景）
        ├─ kind: "rescue"    受困角色，走近出互动键
        ├─ kind: "boss"      关底怪兽，多阶段
        └─ kind: "chest"     奖励宝箱 + 结算
```

孩子只是"一直往右走"，但每走一段就撞上一个**不同类型**的事件。规格书要求"一关至少三种互动"——由校验脚本强制：`tools_check.py` 会拒绝 sections 少于 3 种 kind 的关卡。

### 为什么不做成"关卡编辑器"

因为每关 2–4 分钟、总共 30 关，手摆坐标会摆到天荒地老，而且改一次数值全废。段落只写 `at`（大致 x）和几个参数，**地形照旧由种子随机生成**（现成的 `_build_terrain`），段落自动吸附到最近的平坦地面。同一关重玩时地形一致（种子固定），但**隐藏能量球和额外任务随机**——正好满足规格书第七条"减少每次完全相同"。

## 3. 操作方案（规格书第一条）

```
┌─────────────────────────────────────────────────────────┐
│  ❤❤❤          任务图标条          ⭐0/5    🪙12          │
│                                                          │
│                     （游戏画面）                          │
│                                          ┌────────┐      │
│                                          │ 互动键 │ ← 靠近才出现
│  ┌────┐┌────┐                            └────────┘      │
│  │ ◀  ││ ▶  │              ┌───┐ ┌───┐ ┌───────┐        │
│  └────┘└────┘              │盾 │ │光 │ │ 跳跃  │        │
│                            └───┘ └───┘ └───────┘        │
│                              ┌─────────┐                 │
│                              │  攻击   │                 │
│                              └─────────┘                 │
└─────────────────────────────────────────────────────────┘
```

- **左下**：左右两个大按钮（148px，已验证六岁手指够用）
- **右下**：跳跃（最大，148px）+ 攻击（132px）+ 两个技能（各 116px，带环形冷却）
- **互动键**：靠近箱子/NPC/开关时**淡入到角色头顶偏右**，不占固定位置——不靠近就不存在，不给孩子多余选择
- **宽容度**（沿用并加强现有实现）：
  - 土狼时间 0.14s（已有）、跳跃缓冲 0.16s（已有）
  - **边缘自动攀爬**：跳跃落点差 ≤ 28px 时自动吸上去（新增）
  - **攻击自动瞄准**：攻击时自动朝向 320px 内最近的敌人（新增）
  - 敌人判定框比视觉**大 20%**，角色受击判定框比视觉**小 25%**（新增）
  - 受伤后 1.2s 无敌闪烁（新增）

键盘：←→ 移动、空格跳、Z 攻击、X/C 技能、E 互动。触屏和鼠标共用同一套按钮（`UiKit.is_press` 已统一）。

| 技能教学 | x=800 | 一只**会喷泥球**的小怪，泥球飞来前**先闪光** | 护盾键发光提示 → 按盾挡下 |
| 检查点 | x=1000 | 旗子 | — |
| 小怪 B | x=1200 | 3 只混合小怪（1 只要跳起来打头顶发光点） | 组合使用 |
| **救援** | x=1500 | 笼子里一只小动物在跳 | 走近 → 互动键 → 放出来 → 它跟着你走 |
| 大招蓄满 | x=1700 | 右下角光线技能环填满，闪金光 | — |
| **Boss** | x=2000 | 岩石怪登场，**三段血条**，动作很慢 | 见下方分段 |
| 宝箱 | x=2400 | 大宝箱 + 新技能解锁动画 | 打开 → 结算 → 下一关 |

**Boss 三阶段**（每阶段都有明显预警，且**可以无限重试**）：

1. **第一阶段**：Boss 举手 → **头顶闪光 1.2 秒** → 砸地（地面阴影）。躲开后它手臂发麻，**背上发光点露出 3 秒**→ 攻击那里
2. **第二阶段**：连续扔 3 个石头，**每个都先闪** → 用护盾挡（或跳过去）→ 它累了喘气 → 攻击
3. **第三阶段**：护盾罩住自己 → **必须用光线技能（蓄力）打破** → 破盾后随便打
4. 血空 → Boss **不是死，是累趴下**，坐地上挠头，挥手道别（沿用现有 `leave_happy()`）

**孩子失败时**（规格书第五条）：退回最近检查点，**保留已收集的能量球和金币**，播放鼓励语音。
**连续失败 2 次**：自动降低该关难度一档（Boss 攻击更慢、血更少），并在屏幕上**循环播放操作示范动画**（半透明手指演示按哪个键）。

**互动种类：5（战斗 / 护盾 / 救援 / 技能 / Boss）✅** ｜ 时长约 4 分钟

## 5. 三星规则（规格书第七条）

不再是"失误 ≤2 就两星"，改成**三个独立条件**，结算时三颗星分别点亮：

| 星 | 条件 | 结算画面显示 |
|---|---|---|
| ⭐1 | 完成主线任务（到达旗子） | 旗子图标 |
| ⭐2 | 找到本关隐藏物品 | 宝石图标（没找到显示**灰色轮廓**，不是问号） |
| ⭐3 | 受伤 ≤1 次 | 爱心图标 |

三颗星都独立记录在存档里（`level_stars: {level_id: [true,false,true]}`），
重玩可以只补缺的那颗——这是让孩子**愿意重玩**的关键，比"再刷一次分"直观得多。
