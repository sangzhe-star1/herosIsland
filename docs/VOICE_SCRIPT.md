# 小英雄成长岛 · 配音稿

给孩子录的 44 句话。用你或者孩子妈妈的声音，慢一点、笑着说。

**怎么录**：手机录音就行，一句一个文件，安静的房间，离手机 20 公分。
录完把文件名按下面的对上，整个文件夹发给我，我来切分接进去。

**语气**：像在旁边陪着玩的大人，不是广播。每句话前后留半秒空白。
