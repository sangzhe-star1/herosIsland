# 怪兽素材重新生成 · 提示词与交付要求

给上一版素材包做的修订。设定（名字、属性、世界、技能、弱点、介绍）全部保留，
只重做图。

---

## 一、五条硬要求（上一版就卡在这里）

上一版 15 张卡一张都进不了关卡，不是画得不好，是**交付格式**不对。这五条比
画风重要：

1. **纯色平背景，不要渐变、不要光晕、不要暗角、不要地面阴影。**
   首选 **纯绿 `#00FF00`**（我这边一键抠干净）。如果模型死活要加环境光，
   退而求其次用**纯白 `#FFFFFF`**，同样必须是死平的一块白。
   上一版是蓝灰渐变加发光，15 张里 10 张抠不出来。

2. **不要边框、不要名牌、不要文字、不要卡片版式、不要水印。**
   我要的是"一只怪兽"，不是"一张卡"。图鉴卡我这边用游戏自己的卡框生成——
   这样图鉴里的卡和关卡里打的那只**保证是同一张画**，不会再出现两套图。

3. **全身站姿，正面略带 3/4 侧，脚底平放，整只在画面内，四周留白约 8%。**
   不要半身、不要坐姿、不要动态飞扑。关卡里它要站在地上，脚必须在图片下缘。

4. **1024×1024 正方形，PNG。** 15 只统一尺寸、统一比例——同一只怪兽在图里
   占的高度要差不多（大概画面高度的 80%），我才能按数据里的 `height` 调整
   相对大小。不要有的顶天有的只占一半。

5. **15 只风格必须一致**：同样的描边粗细、同样的眼睛画法、同样的光从左上来。
   一只一只单独生成时最容易跑偏，建议同一个会话里连着生成，或者每次都把下面
   的"通用风格前缀"原样贴上。

## 二、通用风格前缀（每条 prompt 前面都贴这一段）

```
扁平矢量卡通风格的儿童游戏角色，粗而圆润的深色描边，大色块平涂，
只有一层柔和的暗部，没有笔触质感、没有写实渲染、没有噪点、没有材质贴图。
配色明亮饱和、偏亮不偏暗。光线来自左上方。

表情友好可爱：一对又大又圆的眼睛，深色大瞳孔加一点白色高光，
脸颊有淡淡的红晕，嘴巴闭着或者咧开笑，看不到尖牙。

全身站姿，正面略带四分之三侧，双脚平放在画面下缘，整只怪兽都在画面内，
四周留大约百分之八的空白。

背景是纯粹的一块 #00FF00 纯绿，完全平涂，没有渐变、没有光晕、没有阴影、
没有地面、没有边框、没有文字、没有名牌、没有卡片装饰。

1024x1024，正方形。
```

## 四、温和化的三条（这一版专门要改的）

上一版有四只对六岁孩子偏凶——烈焰爪兽、暗影翼兽、雷翼龙兽、赤翼兽。
游戏里的怪兽打完会坐下揉揉头再挥手告别，是"朋友"不是"敌人"，图和玩法要对得上。

具体改法，**不减辨识度**：

- **收牙**：嘴巴闭着抿成一条弧线，或者张开笑但只露圆圆的小舌头，
  不要尖牙、不要血红的口腔。
- **换眼**：把发怒的细长黄眼睛换成又大又圆的眼睛，深色瞳孔 + 白高光。
  眉毛可以有，但要平的或者微微上挑（好奇），不要向内压（生气）。
- **提亮**：整体色调提亮一到两档。深色系的（暗影、雷电）保留深色主体，
  但要加亮部和高饱和的点缀色，不要整只糊在暗里。

角、刺、翅膀、钻头、火焰这些**造型部件全部保留**——孩子认的就是这些，
而且它们在小尺寸的图鉴卡上是唯一还能看清的东西。

## 六、交付方式

一只一个文件，文件名照上表（**不要**带 `monster_01_` 前缀，slug 就够了）：

```
rock_horn.png  steel_spine.png  light_bug.png  twin_horn.png  flame_tail.png
crystal_armor.png  stone_cub.png  blaze_claw.png  sand_fist.png
blue_wing_armor.png  drill_armor.png  red_wing.png  moon_lizard.png
thunder_wyvern.png  shadow_wing.png
```

打包扔进 `tmp/` 就行，和上次一样。

**不用**再出图鉴卡、缩略图、CSV、JSON——上一版的 `monster_catalog.json`
里的设定我已经拿到了，卡片我这边用游戏自己的卡框生成。

## 七、收到后我会做什么

1. 跑 `tools/check_monster_art.py` 逐张验收：背景是不是平的、抠出来干不干净、
   怪兽有没有占满画面、脚在不在下缘、15 张比例一不一致。**哪张不合格我会直接
   告诉你是哪张、差在哪**，不用你猜。
2. 抠成透明 PNG，接进 `data/monsters.json`。
3. 图鉴卡用游戏自己的卡框生成——卡和关卡里的那只是同一张画。
4. 15 只按世界分进关卡（下面这条要先定）。

## 八、一件要先定的事：世界分布不太平均

素材包里的 `world` 字段是这样分的：

| 世界 | 只数 | 谁 |
|---|---|---|
| 阳光公园 | **1** | 山岩幼兽 |
| 夜光城市 | 2 | 钢脊兽、钻甲兽 |
| 怪兽山谷 | 3 | 岩角兽、双角岩兽、沙岩拳兽 |
| 黑暗城堡 | 4 | 炎尾兽、烈焰爪兽、赤翼兽、暗影翼兽 |
| 天空基地 | **5** | 闪灯虫兽、晶甲兽、蓝翼甲兽、月纹蜥兽、雷翼龙兽 |

每个世界六关，第一关就该能遇到一只，最后一关是 Boss。阳光公园只有一只，
孩子头六关只能收到一张卡；天空基地五只挤在一起。

我的建议是调成 **3 / 3 / 3 / 3 / 3**：
把**双角岩兽**（难度 2，造型温和）从怪兽山谷挪到阳光公园，
**月纹蜥兽**（难度 2，害羞）从天空基地挪到夜光城市，
**闪灯虫兽**从天空基地挪到怪兽山谷。
其余不动，每个世界都是"两只小的 + 一只 Boss"。

这只改数据里的一个字段，不影响画。你觉得行我就这么分。
