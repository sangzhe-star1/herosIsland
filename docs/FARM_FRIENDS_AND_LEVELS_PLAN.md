# 农场伙伴、委托与丰收关卡扩展

日期：2026-10-04。基于 `claude/stoic-bell-a41pfu` / `25ecd52` 与上一轮本地 Blender 优化。

## 本轮要让玩家感受到的变化

农场里多一位可以打招呼的兔兔朋友；订单说明朋友准备做什么，交付后有简短回应；丰收挑战增加不同作物、手势与分拣组合，能主动选择想玩的关卡。仍沿用现有农场、订单、手势、篮子、星级与存档组件。

## 已发现的问题

- 订单顾客有小熊、机器人、小狗，但地图上的角色表现少，订单与角色的联系偏弱。
- 循环订单与一次性订单混在同一队列，前三个循环订单可以永久占位，后面的鸡蛋、面粉委托可能没有展示机会。
- 丰收关卡已有 10 个；入口只自动选择下一未完成关，全部完成后固定重玩最后一关，回选不方便。
- 小狗的低动态设置在运动中打开时会停在跳起的一帧，需要回到脚下基线。
- 仓库清单遗漏鸡蛋和面粉，连带容量统计错误；本轮已修复目录合并、去重、溢出篮回填并补回归测试。
- 世界输入在命中一张面板后截断后续阻挡器，4:3翻页可穿透到菜地；现保留完整有效阻挡器列表。

## 实施范围

1. **兔兔朋友**：用同一 Blender 摄影棚生成长耳、围裙、挎篮模型及 PNG/GLB/源场景，放入现有世界装饰层；扩展既有 SceneryLife 的招呼反应，点击有短爱心反馈。兔兔不新增背包或奖励账本。
2. **角色动作**：招呼与小狗动作遵守低动态，切换时回到静止基线，连续点击反应数量有界，继续由原世界控制器处理输入。
3. **朋友委托**：新增 6 个带用途与致谢的一次性订单，涉及野餐、分享、烘焙、风车、早餐与秋日准备。沿用原交付扣货和一次性奖励事务；作物/产物与解锁级别要真实可得。
4. **订单轮换**：一次性故事订单优先；可接循环订单按既有完成次数从少到多展示，同分保持配置顺序。旧存档缺少 counts 按零处理，不新增存档结构。
5. **六个新关卡**：`harvest_11..16`，兔兔沙拉、果园果汁、地下寻宝、豌豆野餐、风车早餐、伙伴接力宴。差异来自采收手势、颜色/类别分篮、清理杂物、多订单接力与勇敢模式例外；不只增加数量。
6. **关卡回选**：保留快速进入下一关，在现有菜园界面提供可关闭的关卡选择面板，显示关号、名称、星级，能直接试玩新增内容。
7. **物品栏与收集面板**（用户追加）：底部工具/种子槽、仓库面板和溢出收集篮统一奶油与浅木色表面；作物与篮子使用项目3D图，补做小铲和洒水壶模型。选中态、数量、容量、升级和关闭保持清晰，沿用原拖动组件和收获账本。先按仓库理解“收集弹窗”，用户若指定其他面板继续纳入。

## 追加：提高物品栏信息密度

用户指出第一版暖色托盘和仓库仍然太疏。本次继续调整布局，而非只换配色：

- 将170px高的底部区域压缩到140px；保留两行可触控目标和按住放大的底部安全距离，减少无内容边距。
- 用户继续要求收起顶部大标题：默认不创建“星光菜园”标题牌，顶部84px→68px。1280×720时上下栏合计释放46px地图高度。
- 丰收挑战进一步改为88×48px图标入口：下一作物/完成星星、播放箭头与完成数；旁边48×48px四格图标打开选关，移除常驻“丰收挑战”和“选关”文字。中文/英文说明留在悬停提示中，保留直接开下一关与回选两条操作路径。
- 工具改为紧凑分组；种子目标约64px宽，让当前14种作物同屏可见，减少翻页。
- 仓库格增加作物名称，图标、名称与数量形成可扫读的紧凑网格；容量、升级条件和操作并到顶部。
- 根据用户圈图继续收小收集面板字号：标题30→22px，仓库/升级/取消按钮26→18px，总量26→20px，物品数量18→16px；标题区与操作行上移，面板406→390px。原物品名称14px和图标40px保持可辨。
- 溢出篮、任务提示、装饰入口重新分配空闲位置；收获飞行终点仍使用共享几何，不出现落点跳动。暂存摘要最多两类＋其余种类数，点击可在同一收集面板完整查看全部暂存物品。
- 任务提示使用显式dense布局，右列继续显示每日进度和订单预览；默认共享布局保持。种子抓取限定在本格内，避免小行距下误抓上排工具。
- 以同存档双比例截图对比前后，并重跑拖种、翻页、真实触控、容量与溢出回归。
- 回归发现并复现鼠标/触摸混流：Godot先分发触摸的模拟鼠标，原输入控制器会让额外鼠标悬停移动改变手势累计距离与种子落点。现有FarmWorld与DragField忽略镜像事件、鼠标移动仅在LEFT掩码按下时参与；Control按钮继续沿用原输入。新增双比例混合输入、正常鼠标和触摸的回归，没有关闭测试中的真实输入或靠重试跳过失败。
- 测试窗口设置unfocusable / mouse_passthrough，防止用户桌面鼠标在自动按下与抬起之间移动原生按钮的悬停目标。注入的鼠标、触摸和混流仍走同一Input.parse_input_event→viewport→GUI路径；这两项窗口标记仅位于测试，不改玩家窗口。

## 不变量

- 丰收只计算挑战成绩，不把关卡作物写进菜园仓库；菜园交付仍由现有事务账本控制。
- 未来订单不能提前消耗；可用目标判定、篮子解析、提示与真实点击保持同一来源。
- 新订单奖励高于同篮作物的市场价格，循环订单不重复发一次性木板。
- 新角色、爱心和说明文字不抢作物/设施触控，不覆盖订单与篮区；16:9 与 4:3 都要复验。
- 不增加强制等待、失败惩罚、限时催促或额外账号系统；新增角色文本与关卡名同时提供中英版本。
- 保留上一轮所有本地素材与文档修改；不把已有基线问题写成已解决。

### 复跑与试玩

```bash
cd /opt/heroesIsland
PYTHONDONTWRITEBYTECODE=1 python3 tests/qa_run.py \
  --name farm-friends --suite tests/farm_friends_suite.json
```

该定向suite包含7项探针，覆盖本轮触及的农场与丰收路径。Blender重建命令见源资产说明。

玩家复验：

1. 用Godot 4.7.1打开项目，首次等待新PNG导入完成，进入星光菜园。
2. 查看底部小铲、水壶、种子栏；切换选中种子并拖到可种地块，解锁更多种子后确认14种均可同屏选择。
3. 点击右下仓库篮查看数量；复验收获、鸡蛋/面粉、满仓溢出、空仓提示、升级确认/取消。
4. 查看兔兔伙伴、点击招呼；打开订单板交付野餐等委托，查看短致谢。已有存档按原等级与一次性完成记录展示。
5. 点右上作物/播放图标直接进入下一关；点旁边四格图标回选，最后两页可进入11–16关。第16关三单依次换顾客，勇敢模式最后一单有金色胡萝卜礼物篮。

后续美术余项：小熊、机器人、小狗顾客仍沿用原有符号，和新兔兔3D头像有风格差异；本轮没有声称全角色美术已统一。
