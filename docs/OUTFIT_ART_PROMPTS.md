# 换装素材 · 提示词与交付要求

给英雄小屋用。和怪兽那一版同一套规矩——那一版第二次就全过了，所以这里不重新
发明，只把差别写清楚。

---

## 一、五条硬要求（和怪兽包完全一样）

1. **纯绿 `#00FF00` 死平背景**，不要渐变、不要光晕、不要暗角、不要投影。
2. **不要边框、名牌、文字、卡片版式、水印**。要的是"一件东西"，不是"一张卡"。
3. **1024×1024 正方形 PNG**。
4. **物体占画面高度约 82%**，四周留白约 9%，居中。
5. **同一批风格必须一致**：同样的描边粗细、同样的光从左上来、同样的高光画法。
   建议同一个会话里连着生成，或者每次都贴同一段风格前缀。

## 二、这一批多出来的四条（和怪兽不同）

6. **画物品本身，不要画穿着它的角色**，不要人台、不要衣架、不要模特。
   孩子在卡片上要一眼看出"这是一顶帽子"而不是"又一个小人"。

7. **正面、正放、不倾斜**。帽子开口朝下、鞋尖朝前、披风领口在上。
   斜着画的东西挂到角色身上会歪，而我只能整体旋转，救不回来。

8. **成对的东西画成一对**（两只鞋、两只手套），左右并排、间距约物体宽度的
   三分之一。我会从中间切开分给左右肢。

9. **不要画阴影、不要画地面、不要画反光台面。** 角色身上的光是游戏算的，
   图里自带的影子贴上去就是两层影子。

## 三、通用风格前缀（每条 prompt 前面都贴这一段）

```
扁平矢量卡通风格的儿童游戏道具图标，粗而圆润的深色描边，大色块平涂，
只有一层柔和的暗部和一小片高光，没有笔触质感、没有写实渲染、没有噪点、
没有材质贴图、没有 3D 反光。配色明亮饱和、偏亮不偏暗，像玩具。
光线来自左上方。

只画这一件物品本身，不要画人、不要画人台、不要画衣架、不要画模特。
正面正放，不倾斜，居中，占画面高度约百分之八十二，四周留白约百分之九。

背景是纯粹的一块 #00FF00 纯绿，完全平涂，没有渐变、没有光晕、没有阴影、
没有地面、没有投影、没有边框、没有文字。

1024x1024，正方形。
```

## 四、反向提示词

```
人物, 角色, 小人, 模特, 人台, 衣架, 手臂, 腿, 头, 身体,
边框, 卡片框, 名牌, 文字, 标签, 水印, 签名, UI, 界面,
渐变背景, 光晕, 暗角, 投影, 地面阴影, 倒影, 反光台面, 场景, 桌面,
写实, 厚涂, 油画笔触, 素描, 线稿, 噪点, 布料纹理, 3D渲染, 金属反光,
倾斜, 透视, 侧面, 背面, 俯视, 多个物品, 一堆衣服, 破损, 骷髅, 尖刺武器
```

## 七、交付方式

一件一个文件，文件名照上表，**不要加 `item_01_` 之类的前缀**。打包扔进 `tmp/`。

不用出：卡片、缩略图、CSV、JSON、预览图（预览图可以出，我会自动忽略）。
**卡片上的图和穿在身上的图是同一张 PNG**——所以只要这 24 张。

## 八、收到后我会做什么

1. 跑 `tools/check_monster_art.py`（我会加一个 `--outfit` 模式，放宽"统一比例"
   这一条：帽子和披风本来就不一样大）逐张验收，不合格的直接告诉你是哪张、差在哪。
2. 用 `tools/cut_monsters.py` 抠成透明 PNG（同一个色度键，已经验证过残留绿点为 0）。
3. 成对的（鞋、手套）自动从中线切开，分给左右肢。
4. 逐件挂到角色身上截图，调 `data/character_slots.json` 里的偏移，把 24 张
   接触点全部核一遍发给你看。
