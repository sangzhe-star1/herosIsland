## 一、当前星星和奖励系统分析

### 1.1 现在真实存在的东西

我把现有代码全部读了一遍，不是凭印象写的。现状是：

| 概念 | 存储位置 | 怎么获得 | 怎么消费 | 谁在用 |
|---|---|---|---|---|
| **关卡星星**（累计） | `data.levels[id].stars` → `total_stars()` | 每关 1–3 颗 | 只增不减 | 解锁世界、地图上的 x/24 |
| **可花星星** | `total_stars() - rewards.spent_stars` | 同上 | `spend_stars()` | **道具商店**（回血药 6★、护盾 5★、星星炸弹 8★） |
| **金币** | `rewards.coins` | 每关 `round(基础币 × 星数/3)` | `spend_coins()` | 英雄小屋的换装、奖励中心的贴纸 |
| 经验 | `profile.xp` | 每关 `15+10×星` | 不消费 | 英雄等级 |

### 1.2 这里有一个必须先拆掉的设计错误

**现在星星是两种东西**：既是「我打了多少关」的成绩，又是「我能花多少钱」的钱包。
`star_balance()` 的注释里已经写了作者当时的顾虑——「消费不能让世界重新上锁」——所以他用了 `spent_stars` 这个减数来绕开。

绕得再干净，孩子看到的仍然是：**「我有 89 颗星，买完药就变 83 颗了」**。这正是你第一条要求要消灭的东西。

同时金币是第二种货币，图标是金币，跟星星长得完全不一样，孩子要同时理解两套钱。

**结论：现在是三个概念（累计星、可花星、金币），要收敛成两个（关卡星章、星星币）。**

### 1.3 改造方向

```
关卡星章  ← total_stars()          永久成绩，只增不减，不可消费
                                    图标：地图上那三颗白/金星，保持不动

星星币    ← rewards.coins           唯一的可花货币
                                    图标：黄色星星 + 小圆形边框（新画）
                                    道具商店改成花星星币，spend_stars() 退役
```

`spent_stars` 这个键在迁移时按 1:1 折算成星星币退还给孩子——他已经花掉的星星变成等值星星币，账面上只多不少，不会有人觉得东西被拿走了。

### 1.4 现在能挣多少钱（实测，不是估算）

按现有规则（**只付「进步的部分」，重打不刷钱**）算出来的曲线：

| 打完 | 全 1 星 | 全 2 星 | 全 3 星 |
|---|---|---|---|
| 第 1 关 | 14 | 27 | 41 |
| 第 2 关 | 23 | 44 | 67 |
| 阳光公园全通 | 50 | 95 | 145 |
| 夜光城市全通 | 116 | 233 | 349 |
| 怪兽山谷全通 | 182 | 368 | 550 |
| 天空基地全通 | 248 | 503 | 751 |
| **整座岛全通** | **371** | **750** | **1121** |

你要求「正常完成 2–3 关后至少能买一件普通礼物」——按 2 星算，**第 2 关结束时手上有 44 颗**，足够买贴纸（5–15）、帽子（15–25）、披风（20–35）。达标，而且有余量。

### 1.5 你要的六种赚钱方式，现在只有一种

你列了六种星星币来源，代码里**只实现了「完成关卡」**。其余五种需要新增：

| 来源 | 现状 | 建议单价 | 全岛总量 |
|---|---|---|---|
| 完成关卡 | ✅ 已有 | 按星数比例 | 371 / 750 / 1121 |
| 首次拿到三颗星 | ❌ | 10 | 330 |
| 找到隐藏物品 | ⚠️ 有 `found_hidden` 但不给钱 | 5 | 60 |
| 完成救援任务 | ❌ | 5 | 30 |
| 打开关卡宝箱 | ⚠️ 有宝箱但不给钱 | 3 | 99 |
| 完成额外挑战 | ⚠️ 有 challenge rank 但不给钱 | 15 | 120 |

加上之后，**一个认真玩的孩子全岛下来大约 750–1760 星星币**。首版 42 件商品总价约 2100，也就是说第一周目能买下大约六成——剩下的四成正好是「回去拿三星」的动力。这是我要的比例：**买得起，但买不完。**

### 1.6 现有资产盘点（能直接复用的）

好消息是骨架比预想的完整：

* **换装槽位已经有五个**：`hat` / `face` / `suit` / `back` / `colour`，由 `HeroArt` 用矢量代码画出来（`scripts/world/hero_art.gd`），不是贴图。已实现 11 件衣服 + 6 种配色。
* `SaveManager` 已有 `has_outfit()` / `add_outfit()` / `wear_outfit(slot, id)`。
* `SkinnedCharacter.refresh_outfit()` 可以**不重建场景就换装**——试穿要用的就是它。
* 英雄基地（`creative_play`）已经能拖放 16 种贴纸并存档（`rewards.creations.base`）。
* 奖励中心已有徽章（31）、贴纸（12）、怪兽图鉴（4）、成长条（5）。

### 1.7 三个必须提前知道的坑

1. **`bluey` 穿不了衣服。** `SkinnedCharacter._build()` 里，贴图角色和小狗角色**故意不上装**（源码注释写明）。迪迦、赛罗、光之英雄等矢量角色可以。所以 `character_compatibility` 字段不是装饰，是真实约束。
2. **帽子会顶掉角色的头冠。** `hero_art.gd:357`：戴帽子时直接 `return`，跳过 crest 绘制。这跟你「不能遮挡主要辨识特征」的要求冲突，帽子类需要逐个检查，必要时改成帽子与头冠共存。
3. **每件新衣服要画两遍。** 一遍在 `HeroArt`（角色身上），一遍在 `IconLibrary`（卡片图标）。漏掉第二个，商品卡就是空白。

## 四、价格与平衡方案

### 4.1 价格带（与你给的区间对齐）

| 类别 | 你的区间 | 我的首期取值 | 说明 |
|---|---|---|---|
| 贴纸 / 简单动作 | 5–15 | 8 / 12 / 15 / 20 | 第一关就买得起 |
| 帽子 / 小配件 | 15–25 | 18 / 22 | |
| 披风 / 背包 / 鞋子 | 20–35 | 28 / 30 / 35 | |
| 完整衣服 | 35–60 | 40 | |
| 特效 | 25–50 | 25 / 35 / 45 | |
| 基地装饰 | 25–70 | 30 / 45 / 60 | |
| 伙伴 | 60–90 | 60 / 75 / 80 | |
| 座驾 | 70–120 | 70 / 90 | |
| 主题礼盒 | 120–160 | 68（首期只有小礼盒） | 大礼盒放二期 |

**首期 21 件合计 843 星星币**（最便宜 8，最贵 90）。

### 4.2 三条平衡校验（都是算出来的，不是感觉）

1. **前 3 关能买到东西吗？**
   2 星水平：第 1 关 27、第 2 关 44、第 3 关 67。
   最便宜的动作 8 颗、云朵帽 18 颗、贴纸册 20 颗 → **第一关结束就能买第一件。** ✅

2. **会不会太快买光？**
   这里要诚实分两种孩子算，因为「首次三星」那 330 颗对 2 星玩家是**拿不到的**：

   | | 关卡 | 三星奖励 | 隐藏物 | 救援 | 宝箱 | 挑战 | 合计 |
   |---|---|---|---|---|---|---|---|
   | 2 星玩家 | 750 | 0 | 60 | 30 | 99 | 0 | **939** |
   | 3 星玩家 | 1121 | 330 | 60 | 30 | 99 | 120 | **1760** |

   首期 843 颗 → **两种孩子第一周目都能买下全部 21 件**，2 星玩家刚好打平，3 星玩家富余。
   首期本来就该「买得完」——21 件不足以支撑长期收集，**收集的张力要靠二期的 42 件**（总价约 2100，那时 2 星玩家只能买下四成半，3 星玩家八成）。
   如果你希望**首期就买不完**，我把伙伴和座驾各涨 15–20 颗即可，一句话的事。

3. **会不会有一件永远买不起？**
   最贵 90 颗 = 阳光公园全通（2 星）的 95 颗。**没有任何一件需要攒超过一个世界。** ✅

### 4.3 一条硬规则

**关卡星章在任何情况下都不会因为购买而减少。** 星星币是独立的一个数，买东西只动它。
这条要写成测试，不是写成注释。

### 建议新增的 tools_check 规则

这一节是我自己加的，因为这个项目已经被同一类错误咬过三次（世界样式、地图区域、关卡图标——都是「查找表没跟上改名」）：

1. 每件商品的 `icon` 必须在 IconLibrary 里存在，否则卡片空白。

5. 商店里不允许出现随机/概率/抽奖相关字段——**结构上就不给它存在的位置。**

## 九、分阶段实施计划

每一阶段我自己跑完你列的 11 项测试，给出**真实运行截图**，你确认后才提交。

### 阶段 0 · 货币收敛（不动界面）

**测试重点**：买东西后 `total_stars()` 一颗不变；旧存档迁移后星星币只多不少。

### 阶段 1 · 数据层与管理器

**先有测试再有界面**——这个项目吃过太多「看起来对、点下去死」的亏。

### 阶段 2 · 商店主界面
七分类 + 卡片网格 + 角色展示台 + 底部条。先只做换装分类。
