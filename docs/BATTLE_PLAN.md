# 光之战士：奥特曼打怪兽

一个模式，不是第二个工程。三个阶段按依赖排序，每阶段独立提交、独立可玩、
独立验收——和菜园三期同一个形状。

---

## 摸底结论：机器已经造好了，只是散着的

动手前把现有的战斗系统全读了一遍。结论是**打怪兽的零件几乎齐了**：

| 已有 | 在哪 |
|---|---|
| 三技能对决（光束 / 护罩 / 必杀）+ 冷却环 + 怪兽血条 + 3 颗光之生命 | `monster_duel.gd`，1046 行，**唯一做过平板适配的战斗模板** |
| 塔防式打法 + 三选一强化 | `light_defense.gd`，695 行 |
| 记忆／节奏 | `light_echo.gd`，572 行 |
| 15 只怪兽 + 怪兽图鉴 + 首次击败登记 | `monsters.json`、`monster_album.gd` |
| 5 个奥特曼系形象（light_hero / tiga / zero / grigio / yullian）+ 9 个原创 | `resources/skins/` |
| 怪兽动作：受击 `flinch()`、蓄力鼓胀 `puff_up()`、开心离场 `leave_happy()` | `battle/monster.gd` |
| 英雄姿势：`BEAM`（护胸起手式）、翻滚 `roll()`、庆祝、踉跄、`pulse_core` | `hero_art.gd` / `skinned_character.gd` |
| 战斗音效 14 个（beam / charge / ultimate / shield / monster_roar / warn…）+ battle 与 victory 两首曲子 | `assets/audio/` |
| 动效：`burst` / `pop` / `nudge` / `dust` / `shockwave` / `speed_lines` / `no_sign` | `juice.gd` |
| 竞技场背景生成器（`monster_arena` 世界预设 + `arena` 地面） | `stage.gd` / `world_style.gd` |

**所以这个方案不写"造一个战斗系统"，写的是"把它接成一条路，并在接的过程中
把手感修好"。** 从零起一个工程等于把上面这张表抄一遍。

还有一个白捡的能力：**矢量怪兽设计器整套写好了，但从来没被数据用过。**
`monster.gd` 支持 `body_color` / `belly_color` / `accent_color` / `ears`（6 种）/
`horns`（含"发光触角"）/ `spikes` / `eyes`（1、2、多）/ `silhouette`，而
`monsters.json` 里 15 只**一个视觉字段都没填**——因为它们全都有 PNG。
新怪兽只要不重名，就能零美术地画出来。

## 诊断：现在的打怪兽是"点一下，等一会儿"

你要的是**交互性、动作感、体验感**。现在最缺的恰恰是这个，而且原因是具体的：

| 症状 | 位置 | 数字 |
|---|---|---|
| 光束冷却 1.3–1.7 秒，中间只能看灰扇形转 | `monster_duel.gd:137,717` | 最后一关约 **44 次点同一个按钮**，60–90 秒 |
| 冷却期点击几乎没反馈 | `monster_duel.gd:514` | `nudge` 只有 **7px**；开了"减少动效"就**只剩音效** |
| 唯一会动的目标按不中 | `monster_duel.gd:889` | 泥球用 `pressed` 信号 = 按下和抬起都要在球上，而球正在 2.4 秒的抛物线上飞 |
| 怪兽吼叫完全不可交互 | `monster_duel.gd:933` | `mouse_filter = IGNORE`；护罩冷却 4.5–5.5 s 而只持续 2.8 s → 后三关**约一半时间手上没有任何应对手段** |
| 塔防里冷却期点屏幕**毫无反应** | `light_defense.gd:306` | 调的是 `SkinnedCharacter` 上**不存在**的 `pulse_core`。注释写着 "never silence"，实际结果正是 silence |
| 节奏关一半时间不能操作 | `light_echo.gd:386,396` | 一句 4.5–7.6 秒纯观看；点错一次 = **9 秒强制重看**，已答对的部分全作废 |

**"体验感"不是再加特效——是把等待变成动作。** 下面三条设计线全部指向这件事。

另有五处已确认的欠账，顺路清掉：

- `light_defense` / `light_echo` **没有胜利表演**，打完最后一击画面什么都不发生
- `light_echo` **完全没做平板适配**，iPad 上英雄悬空 265px、底下 380px 空草地
- 音效撞车：最后一颗生命没了的那一帧 `try_again.ogg` **响三遍**；打怪播 `coin.ogg`；
  中途放必杀播的是通关号角 `level_complete.ogg`
- 死代码：赛前选招界面 54 行 + 第二种必杀 `burst`，**没有任何关卡配过，永不触发**
- probe 引用的关卡 id 大面积失效（`monster_arena_03` / `star_trials_05` /
  `bluey_park_03` 等全不存在）→ 它们仍然 PASS，但验的是默认值，**不是孩子会玩到的配置**

## 三条设计线

### 一、把冷却换成蓄力（体验感）

**现在**：点一下 → 灰扇形转 1.3 秒 → 才能再点。手指在等。

**改成**：**按住蓄力，松手发射。** 按住时胸灯逐渐亮起（`pulse_core`）、
`charge.ogg` 起来、光束在手里越攒越粗（`Shapes.taper` 的宽度就是充能量）；
松手打出去，攒得越久越粗、越疼、`shockwave` 越大。

- 手指**全程有事做**，等待变成"我在攒"
- 短按也照样打得出（弱一击），所以没耐心的孩子不会被卡住——**没有新的失败方式**
- 全部零件现成：`charge.ogg`、`pulse_core()`、`Shapes.taper`、`Shapes.glow`、`Juice.shockwave`

### 二、怪兽先预警，孩子来应对（交互性）

**现在**：吼叫不可点，只能挨打。

**改成**：出手前怪兽 `puff_up()`（**已经写好了**，注释原话是"让防御键变公平的
关键"）+ 眉毛内压 + `warn.ogg` + 地面震纹。孩子有 **0.8 秒**窗口，三种解法：

| 动作 | 手势 | 结果 |
|---|---|---|
| 挡 | 点护罩 | 弹回去，反伤——现有代码里设计最好的一处，保留 |
| 躲 | 点英雄另一侧的地面 | `roll()` 翻滚（**已存在**）+ `speed_lines` + `dust` |
| 打断 | 把攒好的光束打过去 | 怪兽 `flinch()`，这次攻击直接取消 |

一个预警三种解法 = 真的在互动。而且**三种都不需要读字**。

### 三、泥球要按得中（修 bug）

`goo.pressed` → `ACTION_MODE_BUTTON_PRESS`，按下即中。再给它
`UiKit.breathe`，让它自己说"我可以被拍"——现在的教学是**一次、3 秒、纯文字**。

## 美观：按可检查的数字来

现在的战斗 HUD 有几处一眼能看出的问题，全部对着 `apple-design` 的清单：

| 现状 | 违反 | 改成 |
|---|---|---|
| 三个技能键 124 / 108 / 100 px，描边金 / 蓝 / 黄 | **三个强调色 = 没有强调色** | 一个尺寸家族；**只有"此刻最该按的那一个"是强调色**，其余降到 0.45 |
| 间距散落（24 / 34 / 84 / 574 / 596…） | 没有统一节奏 | 一个 `GAP := 12`，所有间距是它的整倍数 |
| 圆角各处自定 | 不成家族 | 面板 28 / 按钮 20 / 芯片 16，**嵌套 = 外层 − 内边距** |
| 进度是 `"3 / 8"` 数字 | 不识字的孩子读不了 | 一排图：打过的亮、没打的暗 |
| 强化卡说明是 20px 文字 | **全项目"只有文字没有图"最典型的一处** | 图标是主角 + 卡面上直接放 1.5 秒小演示 |
| 技能底板半透明 + 描边 + 阴影 | 双重边框 | 二选一 |

触控目标全部 **≥ 60×60**（儿童档），目标间隙 ≥ 8。

## 阶段划分

### 阶段 1：一扇门，一条路（最小可玩）

- 首页第五张卡片 → 光之战士。`mode: "battle"`、`config.exit_to: "home"`，
  **不在成长岛上**——今天刚建好的机制，一条数据搞定
- 怪兽之路：按图鉴的 15 只怪兽排成一条路，一只一场，形状和丰收八关一样
- 玩法先不动，复用 `monster_duel`
- **只修三个已确认的 bug**：泥球 release 触发、`pulse_core` 不存在、音效三重撞
- 验收：进得去出得来、打得完一只、图鉴登记、返回回首页、两档截图

### 阶段 2：蓄力与预警（手感）

- 蓄力光束替代冷却
- 怪兽预警 + 挡/躲/打断三选一
- 无效点击给真反馈（且**开了减少动效也还有**）
- 死代码二选一：接上线，或删掉
- 验收：probe 量一场战斗里**手指有事做的时间占比 ≥ 70%**

### 阶段 3：好看与收尾（美观 + 体验）

- 按上表重排战斗 HUD
- 补胜利表演（塔防和节奏关现在都没有）
- 强化卡改成图为主 + 演示动画
- 进度改成图
- 补平板适配（`light_echo` 完全没做）
- 修 probe 的失效关卡 id，让它们验真配置
- 验收：两档截图 + 尺寸/间距/对比度的 probe 断言

## 两条红线，先写在这里

**一、不做抽卡。** 塔防里的三选一强化是**同时可见、不花钱、不稀有、不限时**
的选择，不是概率商品——保持这个形状。任何"随机出货""开箱""限时消失"都不做。

**二、版权。** Tiga、Zero、Grigio、Yullian 是有版权的角色，这个 build 只在家里
用。对外发布前从 `data/characters.json` 删掉那几条，游戏会干净地退回
Light Hero。做成模式而不是独立工程，这条退出策略才继续成立——一个**叫**
「奥特曼打怪兽」的独立游戏会把这件事顶到最前面。
