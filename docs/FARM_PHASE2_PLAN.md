# 菜园二期方案（2026-07-30 起草，待 Zane 拍板逐阶段做）

一期交了会生长的地，二期交"这块地是我的"。三件事，按依赖排序，每阶段
独立提交、独立可玩、独立验收——和空间化改造一个节奏。

## 已完成的前置（本批）

**canvas_id：创意画布按房间分架。** creative_play 的存档钥匙原来是写死的
"base"，一期只有英雄基地一间房所以没炸；二期装饰一进来，两间房共一把钥匙
= 装饰菜园会盖掉英雄基地里摆好的贴纸。现在钥匙来自关卡数据
（`config.canvas_id`，缺省用关卡 id），英雄基地锁定 "base" 一张贴纸不丢。
tools_check 5u 禁止字面量钥匙回潮；studio_probe 守"两间房两个架子"。

## 阶段 1：菜园装饰（2026-07-30 已实现，一笔）

- 复用 creative_play 整个模板，新房间 `garden_deco`，`canvas_id: "garden"`。
  入口：菜园里一个"装饰模式"按钮（花盆图标），进的是同一块农场的背景 +
  贴纸栏换成花园主题（栅栏、花盆、风车、稻草人——素材包里都有）。
- 摆好的装饰**在菜园正常模式里也画出来**（garden_screen 读同一个
  creation，只画不可拖）。这是和英雄基地不一样的一步，也是"我的菜园"
  的全部意义。
- 验收：摆三个离开再进还在；装饰不挡地块的可点区（DragField 优先）；
  英雄基地的贴纸原封不动。——三条都进了 garden_touch_probe。
- 落地时的两个实况：装饰渲染在 FarmWorld 的 child 1（地皮之上、床和房子
  之下——图层靠孩子顺序不靠 z_index，z=-1 会沉到草皮底下）；房间坐标按
  比例映射到整个 2200×1150 世界，所以装饰散布全农场、跟着镜头平移走，
  有些会被床半挡——这是"装饰是农场的一部分"的代价，孩子在意再调。
- 入口图标用了现成的 sticker_book（素材包的栅栏/风车/稻草人是 PNG，
  没接进画图标的管线，此期贴纸栏用画出来的园艺图标）。

## 阶段 2：食谱解锁（预计一笔）

- `unlocked_recipes` 从零读零写变成真账本：仓库凑齐某组合（如 3 番茄 +
  2 生菜）→ 小熊来访时教一道"菜谱卡"，进图鉴式的食谱页（复用奖励中心
  卡片语言）。不做烹饪玩法，只做收集——加工小屋是三期的事。
- 验收：解锁一条后存档往返仍在；重复凑齐不重复解锁。

## 阶段 3：farm_visitors 常客系统（预计一笔）

- `visit_log` 已在记录；`farm_visitors` 变成"谁常来"：同一 NPC 第 N 次
  来访解锁一句新台词/一个小礼物。纯数据驱动，不加新场景。

## 明确不做（还是三期）

## 风险与前置检查

- 装饰画进 garden_screen 时注意 z 顺序（地块 > 装饰 > 背景）和
  `poke/DragField` 的命中优先级——首页 clear_lane 的教训：看不见但
  能点的东西比挡住的更糟。
- 贴纸数量上限（建议 12）：creation 列表无上限会长进存档。
